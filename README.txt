# Personal Vision Portfolio

A minimal, dark-themed GitHub Pages landing page for a student and aspiring developer.

## Files
- `index.html` — website
- `profile.jpg` — profile photo
- `intro.mp4` — add your finished voice intro here (not included yet)

## Publish on GitHub Pages
1. Create a repository named exactly `shivpartapsinghania.github.io`.
2. Upload these files to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Your site will be published at `https://shivpartapsinghania.github.io`.

## Customize
In `index.html`, replace `Your Name` with your display name.
When you have your finished intro video, upload it as `intro.mp4` to the root. The video player will use it automatically.

Keep your intro short, genuine, and focused on learning and your vision.
